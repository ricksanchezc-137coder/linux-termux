#Módulo 10 — Rede básica no terminal



Ferramentas de rede via terminal: ping (teste de conectividade/latência), curl (requisições HTTP/genéricas), wget (download de arquivos). ss/netstat indisponíveis no Termux — Android 11+ bloqueia sockets netlink pra apps sem privilégio de root; contornado testando portas locais via curl (servidor python3 -m http.server em background).
